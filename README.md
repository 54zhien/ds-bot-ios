# DS Bot iOS

An independent iOS client for DS Bot. One Expo React Native app, built here, signed outside this repository, installed by the person who runs the Bot team.

Nothing runs on the phone: every turn, tool, model call and stored message stays on the computer that hosts the Bot team. The phone shows the team and drives it over an end-to-end encrypted link.

## Layout

| Path | What it is |
|---|---|
| `mobile/` | the app: screens, navigation, the encrypted link, the team store |
| `link/` | the encrypted link to the computer, shared with the desktop build |
| `ds-bot/package.json` | the release version; `mobile/app.config.js` derives `ios.buildNumber` from it |
| `ds-bot/src/client/` | themes, inks, characters, i18n, icons: imported so the phone keeps the desktop look |
| `ds-bot/src/shared/` | protocol pieces the app renders: IM platform names, mentions, group replies |

`mobile/` imports the other two trees by relative path, so those directories keep their names here and move together.

## Build

```sh
npm ci --prefix link
npm ci --prefix mobile
npm run --prefix mobile typecheck
npm run --prefix mobile test
```

`.github/workflows/ios.yml` produces an unsigned IPA on a macOS runner, through `workflow_dispatch` or a tag matching `ios-v*`. It asserts the result is unsigned and complete rather than trusting the export. `.github/workflows/ios-toolchain.yml` reports the Xcode and iOS SDK the runner images actually carry; trigger it with a tag matching `ios-probe-*`.

`ios/` and `android/` are generated by `expo prebuild` during the build and are not committed.

## Install

The IPA is unsigned on purpose: signing belongs to whoever installs it. Sign with your own certificate, and carry the entitlements the app needs — `aps-environment`, the notification extension's bundle, the app group and the keychain access group.

## Provenance

The app shares its UI sources, the link layer and the protocol pieces with [DS Bot](https://github.com/Fei2411/DS-Bot), which is Apache-2.0. Those files stay under that licence and their notices are in `NOTICE`. Everything in `mobile/` and `.github/` is maintained here.
