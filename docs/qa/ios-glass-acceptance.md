## B 组 · 观察项（不阻塞，但要结论）

| 编号 | 项 | 怎么看 | 判据 | 对应风险 | 实测 |
|---|---|---|---|---|---|
| B1 | 玻璃通透度 | 顶栏、输入框、dock 卡、设置卡同屏，浅色深色各截一张 | 像玻璃不像灰块；背景透出不过糊不过清；浅/深各一句结论 | GlassView tint 与背景混合 | |
| B2 | 顶栏模糊带位置 | 滚到底再滚到顶，盯顶栏边缘的模糊渐变 | 应在顶栏一侧；若跑到屏幕底部，记「top/bottom 要对调」 | scrollEdgeEffects 四边 soft 的 edge 配置 | |
| B3 | 原生按压高亮 | 按住顶栏按钮、dock 卡、设置卡各 1s 再松，多页各试一次 | 有原生 highlight/变暗/缩放；完全没有则记「玻璃层在 Pressable 内层，未触发」 | Pressable 包裹顺序 | |
| B4 | 44 点击目标真够大吗 | 单手拇指连点返回、Search、Plus、Chevron、Gear、Stop 各 5 次 | 误触 ≤1 次；命中区明显大于图标外框 | 图标默认值上调了但 hitSlop 没跟 | |
| B5 | 气泡与玻璃对比 | 同屏看自己实色气泡、对方气泡、玻璃输入框、玻璃 dock | 层次分得清；实色气泡不被玻璃吃掉 | 全局玻璃后实色组件对比度下降 | |
| B6 | 侧边对话页 | 看透明顶栏、返回玻璃控件、bot 信息胶囊、底部玻璃输入 | 胶囊只向右伸长不居中拉；顶栏不挡第一条消息；输入能发 | 胶囊 flex 方向与透明 header | |
| B7 | 输入状态悬浮条 | 让 Bot 处于「输入中」，盯输入框上方玻璃条 | 贴住不重叠；长文字不溢出；消失无残影 | absolute 定位与键盘避让联动 | |
| B8 | 性能发热 | 连续滚聊天 3 分钟，摸机背、看电量掉幅 | 温热可接受；掉电 ≤3%；烫或掉电明显则记「blur 层过多」 | 多层玻璃叠加 | |

## 跑完这份清单需要的条件

- 设备：iPhone SE / 主流双机 / Pro Max / iPad 各一台（A10 另需一台 iOS 17 或 18）
- Host：可随时断网与睡眠
- 身份：Main Bot 与普通成员各一个
- 产物：重签后的实际 bundle id 与 buildNumber、每版 .xcarchive 与 dSYM 位置

这版同时改了网络层，「断网 → 重连 → 重试」的步骤与判定不在本表里，单独一份：[`ios-reconnect-checks.md`](./ios-reconnect-checks.md)。三组场景（短断网 / 长断网 / 电脑端断开）不跑，不算验完。那份额外写了 `linked` 与 `online` 两个状态怎么区分。
