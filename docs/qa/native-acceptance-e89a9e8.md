## 1. 首次启动

- [ ] 1.1 冷启动 → 聊天页出现：标题「对话」、空态「与电脑配对后开始对话。」、顶部状态条「未配对」；不黑屏、不闪退（CI 冒烟只能证明进程活着，黑屏要靠这一条）
- [ ] 1.2 杀进程再冷启一次 → 同样正常

## 2. 配对（扫码与粘贴两条路，至少各试一条）

- [ ] 2.1 扫码：左上角按钮 → 「与电脑配对」面板 → 「扫描二维码」→ 允许相机 → 对准电脑端 DS Bot → 设置 → 手机 的二维码 → 自动回填并开始连接；相机被拒时页面提示改用粘贴链接（那行提示是英文，已知）
- [ ] 2.2 粘贴：电脑端复制配对链接（`dsbot://pair?…`）粘进输入框 → 点「连接」→ 面板状态依次「正在连接…」「正在等待电脑…」「已连接」
- [ ] 2.3 成功 → 配对面板自动关闭，状态条走「正在连接…」「正在检查电脑…」后整条消失（在线是安静态，不占屏）；之后杀进程冷启 → 自动重连，不需要重新配对
- [ ] 2.4 失败路：粘一个残缺链接 → 面板报的是人话（说明哪里坏了），「连接」按钮恢复可点，不闪退

## 3. 看到 Bot

- [ ] 3.1 左上角打开抽屉 → 列出电脑上的 Bot 与群，搜索框「搜索团队」能打字过滤；点一个 Bot → 标题变成 Bot 名带「⌄」，空态「还没有消息」
- [ ] 3.2 团队还没有 Bot 时 → 抽屉顶部「还没有 Bot」+ 蓝底「新 Bot」按钮，点它进创建页（在线才有这个入口）

## 4. 发一条消息（输入框三态 `453252e`）

- [ ] 4.1 未聚焦：单行胶囊 + 灰底灰箭头的发送键，点不动 —— 空内容发不出去
- [ ] 4.2 点输入框 → 胶囊变编辑卡长高，底部控制栏出现「+」与发送键，光标在左上；打字后发送键变实色可点；多行时卡片随之长高、约半屏封顶后文本区内部滚动
- [ ] 4.3 点发送 → 自己的气泡立刻上屏带「发送中…」，输入框清空回胶囊，列表自动贴底；几秒内「发送中…」被带时间戳的正常气泡替换（电脑回执到达）
- [ ] 4.4 点「+」选 1–2 张照片 → 底部缩略图条出现、单张可移除（「移除照片」）；发出后气泡带缩略图

## 5. 收到回答

- [ ] 5.1 Bot 回复逐段长出来；带「用了 N 个工具 · 想了 X 秒」的步骤行居中显示，点它可以展开 / 收起工具清单
- [ ] 5.2 相邻折叠（`30fb195`）：同一 Bot 连发几条 → 只有最后一条带时间，前面的不带；你自己发的每条都带时间

- [ ] 5.4 点开某 Bot 的侧问（标题右侧按钮）→ 还没有侧问记录时显示「问问目前做到哪了」

## 6. 切对话（`e89a9e8` + `9b2473f`）

- [ ] 11.3 断网期间有消息在途 → 恢复后那条标红「未发出，点按重试」

## 12. 恢复

- [ ] 12.1 短断网（10 秒级）：网络回来后自动接回（退避 1s、2s、4s…抖动 ±20%），几秒到十几秒内状态条消失、能继续收发，**不出现**「离线」判定态
- [ ] 12.2 长断网：判定成「离线」后**不会自动接回** —— 这版重试阶梯走满约 60 秒就停（与 RN 版不同），必须点「重试」
- [ ] 12.3 点「重试」→ 状态走「正在连接…」「正在检查电脑…」→ 在线；页面回到未选对话状态（重试是重开整条链路），从抽屉重进对话，消息都在
- [ ] 12.4 点失败的红气泡 → 「消息未发出」面板 → 「重试」重发成功变回正常气泡；「丢弃」直接删掉
- [ ] 12.5 把电脑端整个关掉再测 → 状态条给的是人话：「连不上你的电脑。」「电脑没有回应。」，不是英文错误码（`7481ed4`）

## 已知未验证（我们自己也没在真机上确认过，别写成「预期正常」）

1. **多图网格抖动**：一条消息多张图按 1–3 列网格排，行高按张数与宽度预先算定（设计上图片解码不会顶动行高）；真机上滚动加载是否抖，未验证
2. **Markdown 复杂嵌套**：代码块 / 表格 / 引用走自绘渲染，链接是安全跳转；嵌套列表 + 引用的断行与间距在真机上没看过
3. **深色模式整体观感**：每页都有配色分支，但整页协调性没在真机确认过 —— 按第 10 步〔观察〕记结论
4. **推送（N3 未做）**：没有任何远程推送；App 必须前台开着才收得到消息。装完收不到通知是预期，不是故障

## 出问题怎么报

1. 在聊天页**长按顶部标题**（或状态条文字）约 0.6 秒 → 弹出「诊断信息」面板
2. 点「**复制诊断信息**」→ 整份 JSON 进剪贴板 → 直接粘贴到对话里发出来，贴给谁都有用
3. 就算忘了粘贴也有底：面板弹出那一刻已自动存一份文件到 文件 App → DS Bot → `Documents/diagnostics/`（文件名 `yyyyMMdd-HHmmss.json`）
4. 点「保存诊断信息」→ 弹出文件名并可复制路径（标题若显示英文「Diagnostics saved」是词典缺口，功能一样）
5. 内容可以放心贴：密钥、配对码、会话密钥、token 一律自动打码成 `<redacted>`（`Diagnostics.swift` 的 Redaction）
6. 崩溃的报告：系统 设置 → 隐私与安全性 → 分析与改进 → 分析数据 → 找 `DSBot-` 开头的 `.ips`，导出后连同上面那份诊断 JSON 一起发
7. 另一个入口：抽屉 → 设置 → 「更新和诊断」→ 有「诊断日志」与「诊断文件夹」两行

## 跑这份清单需要的条件

- 一台 iPhone（iOS ≥ 16.4），装重签后的包；系统深浅色方便切换
- 电脑端 DS Bot 在线、手机访问打开；网络可随时断（关 Wi-Fi / 飞行模式），电脑端进程可随时停
- 有一个能连续回复的 Bot 与一个群（第 5、9 步要用）；想让 Bot 停在待办状态，让它调一个需要批准的工具即可
