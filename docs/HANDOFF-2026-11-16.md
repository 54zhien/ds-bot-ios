## 4. 怎么构建（重要：本地不能编译）

**这台机器是 Windows，没有 Xcode，也不装 Swift 工具链。所有编译、测试、出包都在 GitHub Actions 上。**

```bash
# 编译 + 测试原生（push 到 main 且动到 native/** 时自动触发）
gh run list --workflow ios-native.yml --limit 3

# 端到端（要验协议互通时手动跑）
gh workflow run ios-native-interop.yml --ref main -f runner=macos-26 -f xcode_version=26.6

# 出原生未签名 IPA
gh workflow run ios-native.yml --ref main -f runner=macos-26 -f xcode_version=26.6
```

**注意两个 CI 特性（都踩过）：**
1. `ios-native.yml` 的 compile job 设了 `concurrency: cancel-in-progress: true`——**编译在跑的时候不要推新提交**，否则会把正在跑的那次取消掉。
2. `xcodebuild test` **不把 shell 环境变量传给测试进程**。所以 interop 的端点配置是"host 脚本写出 Swift 文件 → 再 xcodegen generate"的方式注入（`native/Tests/InteropTests/InteropConfig.generated.swift`，已 gitignore）。

## 5. 协议不变量（改任何一端前必须知道）

权威文件：`docs/link-protocol-spec.md` + `docs/link-test-vectors/`。**任何语言的重写都要拿向量逐字节比对**，不要靠"能连上"判断。

- **deviceId 必须由身份公钥派生**：`"d-" + base64url(sha256(rawPublicKey32)[0..<16])`（`link/src/keys.ts:27-31`）。服务端会重算校验，不一致直接 `AUTH_INVALID`。
- **hello.ack 的线缆键是 `protocol`**（Swift 属性叫 `protocolVersion`），字段顺序见 `frames.ts`；可选字段缺失就整键省略，不要写 `null`。
- **JSON 键序有意义**：TS 用对象字面量顺序。Swift 侧**不能**用 `JSONEncoder`（它的对象存储无序），必须手写 `OrderedObject`/字符串拼接。`/` 不转义。
- **counter 只要求严格递增**，不要求连续；重连是全新 Noise 会话、counter 归零。
- **分片阈值 48 KiB**：4 KiB 消息不分片（向量里 `fragments` 为空），要测边界用 100 KiB 那组。
- **配对码只在 Noise 握手内部的 hello 里传**，不放明文控制帧（中继不可读是设计前提）。配对码成功一次即作废。
- **noise prologue 绑定 connectionId + 双方 deviceId**（`noise.ts:127-134`），改它等于全版本一起断。

## 6. 已知坑（每条都是真踩过的）

**Swift 6 / 并发**
- async 上下文禁止裸 `lock()/unlock()`，用 `lock.withLock { }`，且所有共享状态读写必须在同一个闭包内。
- 不要在持锁时调用回调（会死锁）；先取值、锁外调用。
- `Curve25519.KeyAgreement`（X25519）≠ `Curve25519.Signing`（Ed25519），Noise 必须用前者。
- 函数参数名与函数名同名会遮蔽调用（`value(_ value:)` → `items.map(value)` 编译失败），改名 `render`。

**Xcode / 工程**
- 有 `UIApplicationSceneManifest` 但 `UISceneDelegateClassName` 解析不到 → 启动黑屏，**不是编译错误**。CI 只能验编译，黑屏要靠真机或模拟器启动截图。
- XcodeGen 的 `info.path` 会生成 plist，但目录要能写。
- 测试 target 若是 logic test（无 host app），不能用 `@testable import`，源码要直接进该 target 的 sources。

**Native 版特有**
- iOS 26 Liquid Glass（`expo-glass-effect` 那套）在 RN 里放进 transform 动画层会崩——**原生版没有这个问题**，但 RN 版仍有该限制（已冻结，不必修）。
- `LinkSession.setStatusHandler` 注册时会**先回调当前值**（给 UI 初值用）；测试与 UI 都不要把它当一次状态迁移。
- `PhoneIdentity` 用 `Curve25519.KeyAgreement`（X25519）生成，不是 `Signing`/Ed25519；换错会让 Noise 握手失败且错误信息不指向算法。
- 原生输入框要照 zen（`D:\DSHDev\zen\Zen-Agent\App\Conversation\ComposerHostView.swift`）：UITextView + `positionPlaceholder()` 按 caretRect 定位、`UIVisualEffectView` 表面、`containerConcentric` 圆角、键盘时序动画、控制栏 52 预算。

## 9. 风险

- **真机未验证**：原生版到目前为止只在 CI 里跑过测试与 interop，**一次都没装到 iPhone 上**。第一个原生包很可能暴露启动、Keychain、网络权限（ATS）层面的问题。
- **ATS**：`ws://` 在真机上会被 ATS 拦；正式必须 `wss://`。本地调试若要用 `ws://`，需要 Info.plist 例外，别带进正式包。
- **配对链接来源**：原生版只能粘贴链接，扫码未实现；用户目前的配对码从电脑端 DS Bot 获取。
- **RN 版与原生版并存**：bundle id 已隔离（`.native` 后缀），但两台 App 会共用同一台电脑的配对记录，注意别互相顶掉（`CONNECTION_REPLACED`）。
